# V0.5 Product Scope

SolarLead wird von einer reinen Lead-Plattform zu einem **Lead Operations System**.

### Engine A – Own Acquisition
Organic traffic -> tracked funnel -> buyer/geo score -> call queue -> verified/sales-ready -> sale.

### Engine B – Setter-as-a-Service
Client inbound lead -> API/CSV ingestion -> client script -> setter qualification -> qualified/appointment/callback -> feedback/export.

### Datenpipeline für später
Alle Quellen normalisieren auf denselben Lead:
- own web funnel
- widget/referral/QR
- client API
- client CSV
- future Meta webhook
- future Google lead webhook
- future CRM/web-form adapters

Keine privaten Personen aus Gruppen/Webseiten scrapen. Die Pipeline ist für freiwillig eingereichte bzw. vom Auftraggeber rechtmäßig bereitgestellte Leads gedacht.
